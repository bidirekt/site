# Contributing to the Bidirekt website

## Bugs and feature requests

Open an issue in this repository, with the **Bug report** or the **Feature request** form.

## Questions

For questions about using Bidirekt, read the docs at https://bidirekt.com/docs.

## Pull requests

Fork the repository, create a branch, and open a pull request against `main`. `npm run check`, `npm run lint` and `npm run build` must pass before it is merged; CI runs the three on every pull request.

## Security

Report a vulnerability as [SECURITY.md](SECURITY.md) describes, never in an issue.
